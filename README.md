# CodeCambo — Code. Build. Run. Ship.

Lightweight IDE for Laravel / PHP / Python / Django / JS / Vue / React / SQL.

- `backend/` Django 5 + DRF + Channels. Accounts, settings sync, workspaces, releases (auto-update feed), download page.
- `desktop/` Electron app: Monaco, xterm.js (+node-pty), Git, runner. All local work happens in the main process behind a `contextBridge`; no local server is opened.

## Run
```
cd backend && python -m venv .venv && .venv/Scripts/pip install -r requirements.txt
python manage.py migrate && python manage.py seed && python manage.py runserver

cd desktop && npm install && npm run icons && npm start
```
Set `CODEFORGE_API` to point the app at a deployed backend (default `http://127.0.0.1:8000/api`).
Build installers: `npm run dist:win | dist:mac | dist:linux` (run on the matching OS).

## Extensions & settings.json
Open it from Settings → *Open settings.json* (or the palette). Extensions are declarative JSON (themes, snippets, file associations) and never execute code.
```json
{
  "extensions": ["https://example.com/my-ext.json"],
  "customExtensions": ["C:\dev\hello-extension"],
  "disabledExtensions": []
}
```
`extensions` URLs (https only) are downloaded at startup / on *Reload Extensions*; `customExtensions` are local files or folders containing `extension.json`. See `desktop/examples/hello-extension`.

## Security model
Path allow-list (only folders you opened), protected system dirs, deletes go to Trash with confirmation, git subcommand/option allow-list, tokens in OS credential storage, source code never sent to the server.
Tests: `node desktop/scripts/security-test.js`, `python backend/manage.py test core`.

## Not done / known gaps
No LSP (PHP/Python diagnostics, go-to-definition for them), no real debugger adapter (Debug starts the process with debug flags), pull requests/issues not integrated, auto-update opens the download rather than patching in place, icons `.ico/.icns` are generated by electron-builder from `build/icon.png`, installers untested on macOS/Linux.

## Shortcuts
Windows installer creates Desktop and Start Menu shortcuts (and "Open with CodeCambo"). Running from source: `npm run shortcut` in `desktop/` puts a launcher on your Desktop.

## Releasing installers
Windows: `npm run dist:win` (works on Windows). macOS and Linux installers must be built on those systems; the workflow in `.github/workflows/release.yml` does it for all three:
`git tag v1.0.0 && git push --tags` builds the installers and attaches them to a GitHub Release. Then set `available: True` in `backend/core/site.py`.
