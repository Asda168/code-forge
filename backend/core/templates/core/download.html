Editor

Move through code at the speed of thought.

Built on the Monaco editor, with the navigation tools you already know.

  • Multi-cursor editing, folding, minimap, split editors and tabs.
  • Quick Open any file with Ctrl P; search the whole project with Ctrl Shift F.
  • Go to definition with F12, including Laravel views, controllers, routes and config via the built-in Laravel extension.
  • A file explorer with the Symbols icon theme and JetBrains Mono out of the box.

Terminal

A real terminal, one keystroke away.

Full PTY terminals live in the panel under your editor, so builds, servers and scripts stay next to the code.

  • PowerShell, CMD, Git Bash, bash and zsh, whichever are installed, with a shell picker.
  • Split panes side by side or stacked, with tabs and resizable dividers.
  • Toggle with Ctrl `, split with Ctrl Shift 5. Links open in your browser.

Source control

Git, without leaving the editor.

Review, stage and commit from a panel that mirrors your project structure.

  • Changed files as a folder tree, with stage, unstage, discard and right-click actions.
  • Commit with Ctrl Enter, generate a commit message, then Sync or Publish Branch.
  • Switch, create, rename and delete branches from the branch selector.
  • Side-by-side diffs, inline merge-conflict resolution, blame, file history and stashes.

Run

Open a project. Press Run.

Asta IDE recognises common project types from their files and offers the usual way to start them.

  • Detects Laravel, Django, Node.js, React, Vue and plain PHP projects.
  • Run, Debug, Stop, Stop all and Restart, with F5 and Shift F5. Each run configuration gets its own terminal, so several can run at once.
  • Laravel projects also list Artisan commands such as route:list, migrate and make:model.

Extensions & customization

Make Asta IDE yours.

Extensions are declarative JSON (snippets, themes and file associations). They never execute code on your machine.

  • {{ extensions|length }} built-in catalog entries: snippet packs, file types and colour themes.
  • Rebind any command by clicking it, or edit keyboard.json. Chords like Ctrl K Ctrl S work.
  • One searchable settings page for fonts, terminal, Git and themes.

Seeing “Windows protected your PC”?

The installer is safe but not yet code-signed, so SmartScreen warns about an unknown publisher. It is not a virus warning.

  1. Click More info in the blue window.
  2. Click Run anyway.

If the file was blocked after download: right-click it → Properties → tick Unblock → OK. Or in PowerShell:

Unblock-File "$HOME\Downloads\Asta-Setup-x64.exe"

Not sure which one? x64 fits almost every PC; pick ARM64 only for Snapdragon / ARM laptops.

macOS says it can’t verify Asta?

The current build is not notarized by Apple yet, so Gatekeeper blocks the first launch.

  1. Open the .dmg and drag Asta into Applications.
  2. macOS 12–14: right-click Asta → Open → Open.
  3. macOS 15 (Sequoia) and later: try to open it once, then go to System Settings → Privacy & Security, scroll down and click Open Anyway.

Or remove the quarantine flag in Terminal:

xattr -dr com.apple.quarantine /Applications/Asta.app

One universal build runs natively on both Apple Silicon and Intel.

Which one should I pick?
  1. Ubuntu / Debian / Mint: .deb
  2. Fedora / RHEL / openSUSE: .rpm
  3. Arch / Manjaro: .pacman
  4. Anything else: .AppImage (no install needed)

AppImage won’t start on Ubuntu 22.04+? Install FUSE 2 first (the package is libfuse2t64 on 24.04):

sudo apt install libfuse2

On Ubuntu 24.04, if the AppImage still exits with a sandbox error, use the .deb instead.

      FAQ
      Questions, answered.
      
  
      
    
      Is Asta IDE free?
      Yes. Asta IDE is free and open source.
      
    
      Which operating systems are supported?
      Windows 10/11 (x64 and ARM64), macOS 12+ (Apple Silicon and Intel, universal build) and 64-bit Linux (AppImage, .deb, .rpm and Arch Linux .pacman).
      
    
      Does Asta IDE support Laravel?
      Yes. It detects Laravel projects, can run them in one click, and includes Laravel snippets and file-type support.
      
    
      Does it support Python and Django?
      Yes. Python and Django projects are detected and can be run from the editor, and Django and Python snippet packs are built in.
      
    
      Does it include Git?
      Yes — stage, commit, push, pull, branches, diffs, blame, history and stashes are built in.
      
    
      Can I use Git Bash?
      Yes. The integrated terminal supports Git Bash alongside PowerShell, CMD, bash and zsh when they are installed.
      
    
      Does it support Windows ARM64?
      Yes. There is a dedicated ARM64 installer next to the x64 one in the Windows download card.
      
    
      Does Asta IDE work offline?
      Yes. Editing, the terminal, Git and running projects all work locally. The website, update checks and optional account features need a connection.
      
    
      Where can I report bugs?
      Open an issue on GitHub Issues.
      
    
      Where can I find previous releases?
      Use the version selector in the download section, or browse every build on GitHub Releases.
