Everything you need, nothing you don't

VS Code's speed, PhpStorm's framework awareness, a Git client and a terminal — in one simpler interface.

✎

Monaco editor

Syntax highlighting, IntelliSense, multi-cursor, folding, minimap, split editor and tabs. JetBrains Mono with ligatures by default.

⌨

Integrated terminal

Real PTY terminals with Git Bash, PowerShell, CMD, zsh and bash — running on your own machine.

⑂

Git built in

Stage, commit, push, pull, branches, history graph and a side-by-side diff viewer. Clone over HTTPS or SSH.

▶

One-click run

Detects Laravel, Django, Node, Vue, React and PHP projects and starts the right dev server. Custom run configurations too.

🧩

Extensions

Install snippet packs and themes from the built-in catalog, a URL, or your own folder — declarative JSON, no code execution.

🔒

Private by design

Files, terminal and Git stay local. Your source code is never sent to a server unless you turn sync on. Tokens live in the OS keychain.

Run it from source

Works today on Windows, macOS and Linux with Node 20+ and Python 3.12+.

# desktop app
git clone {{ repo }}.git
cd code-forge/desktop
npm install
npm run icons
npm start

# build an installer for your OS
npm run dist:win   # or dist:mac / dist:linux

# optional backend (accounts, sync, updates)
cd ../backend
pip install -r requirements.txt
python manage.py migrate && python manage.py seed
python manage.py runserver
