FAQ
Questions, answered.

  

    
Is Asta free?
Yes. Asta is free and open source.

    
Which operating systems are supported?
Windows 10/11 (x64 and ARM64), macOS 12+ (Apple Silicon and Intel, universal build) and 64-bit Linux (AppImage, .deb, .rpm and Arch Linux .pacman).

    
Does Asta support Laravel?
Yes. It detects Laravel projects, can run them in one click, and includes Laravel snippets and file-type support.

    
Does it support Python and Django?
Yes. Python and Django projects are detected and can be run from the editor, and Django and Python snippet packs are built in.

    
Does it include Git?
Yes — stage, commit, push, pull, branches, diffs, blame, history and stashes are built in.

    
Can I use Git Bash?
Yes. The integrated terminal supports Git Bash alongside PowerShell, CMD, bash and zsh when they are installed.

    
Does it support Windows ARM64?
Yes. There is a dedicated ARM64 installer next to the x64 one in the Windows download card.

    
Does Asta work offline?
Yes. Editing, the terminal, Git and running projects all work locally. The website, update checks and optional account features need a connection.

    
Where can I report bugs?
Open an issue on GitHub Issues.

    
Where can I find previous releases?
Use the version selector in the download section, or browse every build on GitHub Releases.
