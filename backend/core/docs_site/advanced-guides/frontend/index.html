Advanced Guides

Customize AstaIDE for Frontend Development

React, Vue, previews and themes.

Make AstaIDE comfortable for React, Vue, HTML and CSS work.

#Extensions

InstallFor
React SnippetsComponents and hooks; .jsx / .tsx
Vue SnippetsSingle-file components; .vue
JavaScript SnippetsJS and TS helpers

#Settings

json
{
  "tabSize": 2,
  "wordWrap": true,
  "minimap": false,
  "ligatures": true,
  "bracketColors": true,
  "autoSave": "afterDelay",
  "autoSaveDelay": 500
}

A shorter save delay makes hot-reload dev servers (Vite, webpack) update as you type.

#Preview files

Markdown, HTML and SVG files can be previewed: press Ctrl+Shift+V (Command Palette: Toggle File Preview).

#Layout for UI work

  • Ctrl+\ to split the editor: component on the left, styles on the right.
  • Ctrl+Alt+H hides the header for more vertical space.
  • Ctrl+B hides the sidebar when you want the code full width.

#Theme and fonts

A light theme such as Paper or Light Modern makes it easier to judge light-mode designs. Increase lineHeight to 1.6 for long JSX files.

#Run configuration

Detection gives you npm run dev for Vite, Vue CLI or Next-style projects. Add npm run build and npm run preview as extra configurations.

#Expected result

A split layout with the dev server in the terminal below and instant feedback in the browser.
