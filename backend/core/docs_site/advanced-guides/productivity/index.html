Developer Productivity Tips

Shortcuts and habits that save time.

Small habits that make AstaIDE faster to use.

#Learn ten shortcuts first

Do thisPress
Open any fileCtrl+P
Run any commandCtrl+Shift+P
Find in all filesCtrl+Shift+F
Toggle the terminalCtrl+`
New terminalCtrl+Shift+`
Split the editorCtrl+\
Source ControlCtrl+Shift+G
Run the projectF5
Go to definitionF12
Switch projectCtrl+R

#Use the Command Palette

Almost every setting has a command: toggle auto save, change the theme, open settings.json, reload extensions, toggle the header.

#Let auto save work

The default (afterDelay, 1 second) means you rarely press save. Use onFocusChange if you prefer saves only when you switch away.

#Keep Git tidy

  • Commit small and often; use Generate as a first draft.
  • Keep a feature/… branch per task (Branches).
  • Use the footer Commits tab filter to find an old change by word.
  • Use Stash changes before switching tasks.

#Make shortcuts yours

Rebind what you use most in keyboard.json (Customize Shortcuts).

#Free up space

  • Ctrl+B sidebar, Ctrl+J panel, Ctrl+Alt+H header.
  • Maximize the terminal panel for long-running output.

#Save your setup

Back up settings.json and keyboard.json in a Git repository of your own (Backup and Migration Guide).
