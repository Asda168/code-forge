Keyboard Shortcuts

Complete Shortcut Reference

All default key bindings, generated from the application.

Every default shortcut in AstaIDE. This table is generated from the application's own key map, so it always matches the shipped version.

Note: Ctrl/Cmd means Ctrl on Windows and Linux and Cmd on macOS. Rows marked terminal focused only apply while the terminal has focus. Use the Command id to change a shortcut in keyboard.json (Customize Shortcuts).

#Editor shortcuts that come from Monaco

The editor also provides the standard editing shortcuts, for example Ctrl+D (select next occurrence), Alt+Click (add a cursor), Alt+Up / Alt+Down (move line), Ctrl+/ (toggle comment) and Ctrl+Z / Ctrl+Y (undo and redo). These are not remappable in keyboard.json.
