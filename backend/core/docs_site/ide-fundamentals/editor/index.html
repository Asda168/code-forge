IDE Fundamentals

Understanding the Editor

Monaco-based editing, auto save, minimap, multi-cursor and font zoom.

The editor is Monaco, the engine behind VS Code, wrapped with AstaIDE's tabs, themes and settings. This page covers the everyday editing features and the settings that control them.

#Understanding the editor

Open any file from the Explorer or with Quick Open (Ctrl+P). Changes are saved automatically by default (see Auto save below). A dot on the tab means the file has unsaved changes.

Useful built-in features: syntax highlighting for many languages, bracket matching, code folding, snippets (from extensions), find and replace, and a read-only diff viewer from Source Control.

#Auto save and saving

SettingValuesDefault
autoSaveoff, afterDelay, onFocusChange, onWindowChangeafterDelay
autoSaveDelaymilliseconds (100 to 60000)1000

json
{
  "autoSave": "onFocusChange",
  "trimWhitespace": true,
  "finalNewline": true
}

Save manually with Ctrl+S, save everything with Ctrl+Alt+S, or toggle auto save from the Command Palette (Toggle Auto Save).

#Editor minimap

The minimap is the small overview on the right edge of the editor. Turn it off if you want more room:

json
{ "minimap": false }

Default: true. Restore the default by setting it back to true or deleting the key.

#Multi-cursor editing

The editor supports the standard Monaco multi-cursor commands:

  • Alt+Click adds a cursor where you click.
  • Ctrl+Alt+Up / Ctrl+Alt+Down add a cursor on the line above or below.
  • Ctrl+D selects the next occurrence of the current word; Ctrl+Shift+L selects all occurrences.

On macOS use Option and Cmd in place of Alt and Ctrl.

#Zoom the editor font

Ctrl+= makes the editor font larger, Ctrl+- smaller and Ctrl+0 resets it. When the terminal has focus, the same keys change the terminal font instead.

#Expected result

You can edit, save automatically and change how the editor looks from settings.json or the Settings page.

#Common problems

  • The caret jumps or spaces vanish while typing: update to AstaIDE 1.3.9 or newer, which fixed an auto-save and trim-whitespace interaction.
  • The editor font looks wrong: the font family must be installed on your computer (Editor Colors and Fonts).
