Getting Started

System Requirements

Supported operating systems and the tools AstaIDE works best with.

AstaIDE runs on Windows, macOS and Linux. The IDE itself needs nothing else, but some features use tools that must already be installed on your computer.

#Supported platforms

PlatformPackageNotes
Windows (x64)Asta-Setup-x64.exeInstaller wizard
Windows (ARM64)Asta-Setup-arm64.exeInstaller wizard
macOSAsta-macOS-universal.dmgOne build for Intel and Apple silicon
Linux (x64)Asta.AppImage, Asta.deb, Asta.rpm, Asta.pacmanPick the format for your distribution

AstaIDE is built on Electron 33, so it needs a desktop operating system version that Electron 33 supports (Windows 10 or later, a current macOS release, or a mainstream 64-bit Linux desktop).

#Tools AstaIDE uses

ToolNeeded forRequired?
GitSource Control, Git Bash terminalYes, for anything Git-related
Git for WindowsThe Git Bash terminal profile (Windows)Only if you want Git Bash
PHP and ComposerLaravel and PHP projectsOnly for those projects
Python 3Python and Django projectsOnly for those projects
Node.js and npmNode, React and Vue projectsOnly for those projects

AstaIDE does not bundle these tools. If one is missing you will see an error such as "command not found" in the terminal; see PHP, Python and Node.js Not Found.

#Expected result

You can run git --version in any terminal and get a version number. Do the same for php -v, python --version or node -v for the stacks you use.

#Common problems

  • Git is installed but AstaIDE says it cannot find it: see Git Not Detected.
  • The terminal looks limited (no colours or full-screen apps): the optional node-pty component is missing; see Troubleshoot Terminal Issues.
