#How these docs are organised

Start with Getting Started if AstaIDE is new to you. Every other section stands on its own, so you can jump straight to the topic you need. Use search (Ctrl K or /) to find any setting, shortcut or command.

Note: these pages describe the application as shipped. Settings, shortcuts and file formats are read from the AstaIDE source code when the docs are built, so the reference pages cannot drift from the app.

#Where your configuration lives

WhatHow to open it
settings.jsonSettings page, then the settings.json button (or palette: Open settings.json)
keyboard.jsonSettings, then Keyboard shortcuts, or palette: Preferences: Open keyboard.json
Custom extensionsFolders or files listed under customExtensions in settings.json
