Terminal Guide

Terminal Font and Appearance

Font, size, line height and cursor.

The terminal has its own font and cursor settings, separate from the editor.

#Where to change them

Open Settings, Terminal, Appearance, or edit settings.json:

json
{
  "termFontFamily": "Cascadia Mono",
  "termFontSize": 14,
  "termLineHeight": 1.3,
  "termCursorStyle": "bar",
  "termCursorBlink": false
}

#Settings

KeyWhat it doesValuesDefault
termFontFamilyTerminal font. Empty uses a safe monospace stackfont name or """"
termFontSizeFont size in pixelsnumber13
termLineHeightLine spacing multipliernumber1.4
termCursorStyleCursor shapeblock, bar, underlineblock
termCursorBlinkBlink the cursortrue / falsetrue

#Quick zoom

With the terminal focused, Ctrl+= increases the font, Ctrl+- decreases it and Ctrl+0 resets it.

#Colours

The terminal colours follow your selected colour theme (Change the Color Theme).

#Restore the defaults

Delete the keys you changed from settings.json, or set them back to the defaults in the table above.

#Expected result

Terminal text uses the font and cursor you chose immediately, with no restart.

#Common problems

  • Text overlaps or looks uneven: use a monospace font. A proportional font makes characters collide. Leave termFontFamily empty to use the built-in fallback stack.
  • The font is ignored: the font must be installed on your computer under exactly that name.
