Extensions

Introduction, Browse, Install and Manage

The Extensions view, enable, disable and reload.

Extensions add themes, snippets, file associations and a few built-in navigation features. In AstaIDE an extension is a small JSON file, so it can never run code on your computer.

#Introduction to extensions

Open the Extensions view with Ctrl+Shift+X. It lists extensions you have installed and a catalog of bundled ones you can install with one click. You can search, and sort by relevance, name, recently installed or installed.

#Browse built-in extensions

ExtensionAdds
Laravel SnippetsPHP/Blade snippets, .blade files as HTML, Ctrl+Click / F12 Laravel navigation
PHP SnippetsCommon PHP snippets
Python Snippets / Django SnippetsPython helpers; models, views, URLs
JavaScript SnippetsJS and TS helpers
React SnippetsComponents and hooks; .jsx and .tsx files
Vue SnippetsVue 3 single-file components; .vue files
SQL Snippets / MySQL SnippetsCommon SQL; MySQL specifics
Git Config Files.gitignore and .gitattributes associations
GitLensLine blame, file blame, file and line history, GitLens view
Git BlameWho last changed the current line
Forest, Neon Night, Ocean, Paper, SunsetColour themes (Change the Color Theme)

#Install extensions

  • From the catalog: click Install on a bundled extension.
  • From a URL: the ... menu in the Extensions view, Install from URL…, or the Command Palette. Only https:// URLs to a JSON manifest are accepted (maximum 1 MB).
  • From a local folder or file: list it under customExtensions (Create a Custom Extension).
  • From settings.json: list URLs under extensions, then reload:
json
{
  "extensions": [
    "https://example.com/my-snippets/extension.json"
  ]
}

#Enable and disable extensions

Use the switch on an extension in the Extensions view. Disabled ids are saved in settings.json:

json
{ "disabledExtensions": ["theme-neon", "gitblame"] }

Remove an id from the list to enable it again.

#Reload extensions

After editing extensions, customExtensions or a manifest, run Reload Extensions (download from settings.json) from the Command Palette, or Sync extension sources in the ... menu. It downloads every URL in extensions and rereads your local manifests; errors are reported in a notice.

#Related settings

KeyMeaningDefault
extensionsHTTPS manifest URLs to download[]
customExtensionsLocal manifest files or folders[]
disabledExtensionsIds that are switched off[]
suggestExtensionsSuggest extensions for the project typetrue
dismissedSuggestionsSuggestions you have dismissed[]

#Expected result

Installed extensions show an enabled switch; a theme appears in the Color Theme list and snippets show up while typing.

#Common problems

  • "Invalid extension: id must be lowercase letters, digits, . _ -": fix the id field (extension.json reference).
  • An extension does not load: Extensions Not Loading.
