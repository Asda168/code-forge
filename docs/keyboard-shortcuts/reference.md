## Editor shortcuts that come from Monaco

The editor also provides the standard editing shortcuts, for example <kbd>Ctrl+D</kbd> (select next occurrence), <kbd>Alt+Click</kbd> (add a cursor), <kbd>Alt+Up</kbd> / <kbd>Alt+Down</kbd> (move line), <kbd>Ctrl+/</kbd> (toggle comment) and <kbd>Ctrl+Z</kbd> / <kbd>Ctrl+Y</kbd> (undo and redo). These are not remappable in `keyboard.json`.
