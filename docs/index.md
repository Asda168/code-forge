## How these docs are organised

Start with **Getting Started** if AstaIDE is new to you. Every other section stands on its own, so you can jump straight to the topic you need. Use search (<kbd>Ctrl K</kbd> or <kbd>/</kbd>) to find any setting, shortcut or command.

> **Note:** these pages describe the application as shipped. Settings, shortcuts and file formats are read from the AstaIDE source code when the docs are built, so the reference pages cannot drift from the app.

## Where your configuration lives

| What | How to open it |
|---|---|
| `settings.json` | **Settings** page, then the `settings.json` button (or palette: *Open settings.json*) |
| `keyboard.json` | **Settings**, then *Keyboard shortcuts*, or palette: *Preferences: Open keyboard.json* |
| Custom extensions | Folders or files listed under `customExtensions` in `settings.json` |

See [Open, Search and Edit Settings](settings/open-and-edit.md) for details.
