AstaIDE (the app is named **Asta**) is a lightweight desktop IDE. It puts a code editor, an integrated terminal, Git, a project runner and a small extension system in one fast window, with first-class support for Laravel, Django, Python, Node.js, React, Vue and plain PHP.

## What is AstaIDE?

AstaIDE is an Electron desktop application. The editor is Monaco (the same editor engine used by VS Code), so editing feels familiar: multi-cursor, minimap, find and replace, snippets and themes all work the way you expect.

![The AstaIDE editor with the explorer open](/shots/explorer.webp)

What you get out of the box:

- **Editor** with tabs, split view, auto save, minimap, sticky scroll and bracket colours.
- **Explorer** with file icons, drag and drop, copy and paste, and Trash-based delete.
- **Integrated terminal** with PowerShell, CMD and Git Bash on Windows, split panes and multiple tabs.
- **Source Control** with staging, commit-message generation, branches, history, remotes, stash and inline merge-conflict resolution.
- **Run and Debug** that detects Laravel, Django, Node, React, Vue and PHP projects and gives you ready-made run configurations.
- **Extensions** that are plain JSON: themes, snippets, file associations. They can never execute code.
- **Themes and settings** that you can edit in a Settings page or directly in `settings.json`.

> **Note:** your source code is never sent to a server. The optional AstaIDE backend only handles accounts, settings sync and the release/download feed.

## Who it is for

AstaIDE is for developers who want a fast, focused tool without a long setup. If you work on PHP/Laravel or Python/Django projects and like a terminal and Git close at hand, it is built for you.
