The AstaIDE window has six areas. Learning their names makes the rest of the documentation easy to follow.

![AstaIDE window: activity bar, sidebar, editor and terminal](/shots/editor.webp)

## The areas

| Area | Where | What it does |
|---|---|---|
| **Top bar** | Very top | Logo and the *Search / Command Palette* button. Hide it with <kbd>Ctrl+Alt+H</kbd> to gain space ([Hide the layout header](../themes/layout.md#hide-the-layout-header)). |
| **Activity bar** | Far left | Switch the sidebar view: Explorer, Search, Source Control, GitLens, Run and Debug, Extensions. Settings is at the bottom. |
| **Sidebar** | Left | Shows the selected view. Drag its right edge to resize; toggle it with <kbd>Ctrl+B</kbd>. |
| **Editor** | Centre | Tabs and the code editor. Split it to work side by side. |
| **Panel** | Bottom | **Terminal**, **Problems** and **Debug Console**. Toggle with <kbd>Ctrl+J</kbd>. |
| **Status bar** | Very bottom | Git branch and sync state, problem counts, cursor position, indentation, encoding, line endings, language and editor font. |

## Sidebar views and their shortcuts

| View | Shortcut |
|---|---|
| Explorer | <kbd>Ctrl+Shift+E</kbd> |
| Search | <kbd>Ctrl+Shift+F</kbd> |
| Source Control | <kbd>Ctrl+Shift+G</kbd> |
| GitLens | <kbd>Alt+G</kbd> |
| Run and Debug | <kbd>Ctrl+Shift+D</kbd> |
| Extensions | <kbd>Ctrl+Shift+X</kbd> |

## The Command Palette

Press <kbd>Ctrl+Shift+P</kbd> to run almost any action by name: change the theme, open `settings.json`, install an extension, toggle auto save and more. It is the fastest way to discover features.

## Resizing

- Drag the **sidebar edge** to resize it.
- Drag the **edge above the panel** to resize it; double-click the edge to reset the panel to its default height.
- On a small window AstaIDE keeps the editor at a usable height, and the panel can be maximised with the arrow button in its title bar.

## Expected result

You can name each area and show or hide the sidebar and panel with the keyboard.
