The first time you start AstaIDE you see an empty workspace with a logo and the most useful shortcuts. A few quick choices make it comfortable.

## What you see

- A **start screen** with shortcuts: *Quick Open* <kbd>Ctrl+P</kbd>, *Command Palette* <kbd>Ctrl+Shift+P</kbd>, *Toggle Terminal* <kbd>Ctrl+`</kbd> and *Find in Files* <kbd>Ctrl+Shift+F</kbd>. On macOS <kbd>Ctrl</kbd> is <kbd>Cmd</kbd> for these.
- Your **recent projects** once you have opened some.
- The **Explorer** in the sidebar, waiting for a folder.

## Recommended first steps

1. **Open a project:** <kbd>Ctrl+O</kbd> ([Open Your First Project](open-project.md)).
2. **Pick a theme:** <kbd>Ctrl+K</kbd> then <kbd>Ctrl+T</kbd> ([Change the Color Theme](../themes/color-theme.md)). The default is *Monokai Dimmed*.
3. **Check the terminal:** press <kbd>Ctrl+`</kbd>. On Windows choose PowerShell, CMD or Git Bash ([Open the Terminal and Choose a Shell](../terminal/shells.md)).
4. **Set the editor font** in Settings (default: JetBrains Mono, size 14).
5. **Install helpful extensions** from the Extensions view, for example *Laravel*, *Python* or *React* snippets ([Extensions](../extensions/overview.md)).

## Expected result

You can open a folder, see its files in the Explorer and open a terminal in that folder.

## Common problems

- **The window opens very small or very large:** drag the window edge; AstaIDE remembers the sidebar width and panel height you set.
- **Extension suggestions appear:** AstaIDE can suggest extensions for the project type. Turn this off with `"suggestExtensions": false` ([Settings Reference](../settings/reference.md)).
